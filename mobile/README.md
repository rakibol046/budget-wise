# BudgetWise mobile

A React Native + Expo Android app that uses the same API, accounts, and database as [BudgetWise on the web](https://budget-wise-six.vercel.app/).

## Features

- Sign in, register, verify email with an OTP, resend codes, and select a currency.
- Restore sessions with Android SecureStore; reconnect after a network failure.
- Monthly dashboard with spending, balances, category breakdown, weekly chart, and projected spending.
- Create, edit, delete, search, and filter expenses; link an account and enable recurring expenses.
- Share filtered expenses as CSV using the Android share sheet.
- Set category budgets and copy the previous month's allocation.
- Create and edit accounts, adjust balances, and choose a default account.
- Create, edit, enable, disable, and delete categories.
- Update your profile, password, currency, and light/dark/device appearance.

All financial writes go through the existing backend. An internet connection is required. Recurring expenses are generated by the existing backend, as on the website. Currency preferences change labels, not the numeric amounts.

## Start developing

Use Node.js 22.13+ or 24.3+ (see the supported versions in `package.json`), then:

```bash
cd mobile
npm ci
npm start
```

Open the project with an Expo Go version compatible with Expo SDK 58, or create a native Android development build with `npm run android` after configuring Android Studio. A native build is independent of Metro when built in release mode.

The default API is already configured:

```text
https://budget-wise-six.vercel.app/_/backend/api
```

To use another server, copy `.env.example` to `.env` and change `EXPO_PUBLIC_API_URL`. For an Android emulator, use `http://10.0.2.2:5000/api`; for a physical phone, use your computer's LAN address. Android release builds require HTTPS. Restart Expo after changing the environment. `EXPO_PUBLIC_` values are embedded in the bundle and must never contain secrets.

The React Native app uses bearer authentication, so browser CORS restrictions do not apply to Android. The optional browser preview (`npm run web`) may require a matching backend CORS origin when using a real server.

## Build an installable APK with Expo

No local Android SDK is required for this method. Use your own Expo account and keep its Android signing credentials for future updates:

```bash
cd mobile
npx eas-cli login
npx eas-cli init
npm run build:apk
```

The `preview` profile in `eas.json` explicitly builds an **APK**, which can be installed directly on a phone. Download the APK from the build URL printed by EAS. The `production` profile builds an AAB for Google Play:

```bash
npx eas-cli build --platform android --profile production
```

See [Expo's APK build documentation](https://docs.expo.dev/build-reference/apk/). Change `android.package` in `app.json` before your first published release if you want a different application ID; the current value is `com.budgetwise.mobile`.

## Build locally

Install a full JDK compatible with Gradle 9.4.1 (JDK 17 or newer, including `javac` and `jlink`), Android command-line tools, SDK Platform 37, and Build Tools 37. An IDE's bundled Java runtime may lack the required JDK tools. Gradle can install additional native build components after accepting Android SDK licenses. Set `JAVA_HOME` and `ANDROID_HOME` to your installation paths.

```bash
cd mobile
npm run build:apk:local
```

The script runs Expo prebuild and `assembleRelease`, then copies the APK to:

```text
mobile/artifacts/BudgetWise-preview.apk
```

The local script produces a release-mode **preview signed with the generated debug key**. Use EAS-managed release signing for distribution and future updates. Back up signing keys; APK updates must be signed with the same key. Native `android/` output is generated and ignored by Git.

For a smaller build targeting a modern ARM64 phone:

```bash
npm run build:apk:local -- -PreactNativeArchitectures=arm64-v8a
```

Android 7.0 (API 24) or newer is required by the selected React Native version. An ARM64-only APK requires an ARM64 Android device; the default build script includes all configured architectures. Install by copying the APK to your phone and opening it, or use `adb install -r artifacts/BudgetWise-preview.apk` with USB debugging enabled.

## Verification

```bash
npm run check
npm run export:android
npx playwright install chromium
npm run test:browser
```

Browser tests use sample API responses. They exercise login, registration/OTP/currency onboarding, session restoration, expense create/edit/delete, budget saving, account balances, category management, navigation, incorrect-password handling, and offline recovery without modifying production data. If using an existing Chrome installation instead of downloading Chromium, set `PLAYWRIGHT_CHROMIUM_EXECUTABLE` to its executable path. Python 3 is used to serve the exported preview for these tests.

Before distributing, check login with your own account, OTP delivery, Android date selection, secure session restoration, CSV sharing, and expense/account balance changes on a physical Android device. Browser checks do not exercise native device APIs.

## Source map

```text
App.tsx                  App shell, bottom tabs, Android back handling
src/state.tsx            Authentication, API connection, shared data, theme
src/screens/             Native screens and editors
src/ui.tsx               Shared native controls and dialogs
src/lib/api.mjs          HTTP client and error handling
src/lib/finance.mjs      Date, amount, chart, and CSV helpers
scripts/build-apk.sh     Local preview APK build
eas.json                 Cloud APK/AAB build profiles
```

The web frontend and backend remain separate applications. This mobile app uses native React Native views and does not embed the website in a WebView.
